### Was ist Scaffy?

Scaffy ist ein Lernwerkzeug, um echten UI-Code Schritt für Schritt zu bauen. Du beschreibst in einfacher Sprache, was du möchtest; Scaffy teilt die Lösung in kleine Abschnitte auf und zeigt sie nacheinander in einem Code-Editor.

Anders als Tools, die eine komplette Lösung auf einmal ausgeben, baut Scaffy bewusste Reibung ein: Bevor jeder neue Abschnitt erscheint, beantwortest du eine kurze Konzeptfrage auf einer **Learning Card**. Diese Pause ist beabsichtigt – sie macht aus passivem Abschreiben aktives Verstehen.

Scaffy ist für Menschen gemacht, die framework-basierte UI-Entwicklung lernen, besonders Svelte 5. Die Schrittinhalte einer Session werden auf Deutsch (Kurssprache) generiert; die Oberfläche ist auf Englisch und Deutsch verfügbar.

### So funktioniert es

- **Start** — Beschreibe dein Ziel in einfacher Sprache. Starte eine Session.
- **Session** — Code erscheint im Monaco-Editor als Lernschritte. Eine **Learning Card** blockiert den nächsten Schritt, bis du richtig antwortest. Über die Session-Tabs wechselst du zwischen offenen Lektionen.
- **Falsche Antwort?** — Ein Feedback-Dialog zeigt die richtige Option und eine kurze Erklärung; versuche es erneut, bis das Konzept sitzt.
- **Ask-Panel** — Nutze den Chat rechts für einen sokratischen Tutor, der Konzepte erklärt, ohne eine komplette Lösung auszugeben.
- **Sessions** — Alle deine Lernsitzungen an einem Ort. Jederzeit fortsetzen oder löschen.
